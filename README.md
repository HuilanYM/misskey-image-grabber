# Misskey Image Grabber

[中文](README.md) | [日本語](README.ja.md) | [English](README.en.md)

**抓取 [misskey.io](https://misskey.io/) 用户发布的图片，生成可离线浏览的 HTML 档案** —— 像刷网站一样翻阅：时间线、发布时间、正文、反应、图片画廊，全部本地化，双击即看，无需联网。

Chrome / Edge（Manifest V3）· 零依赖 · 零构建 · 开发者模式加载即用

> ⚠️ 本扩展为**非官方**社区工具，与 Misskey 或 misskey.io 无隶属关系。

---

## ✨ 功能一览

- **按用户抓取**：输入 `@用户名` 或主页链接，自动翻页抓取全部带图笔记（支持断点续抓、暂停/停止）
- **增量档案**：同一用户固定一个档案文件夹，每次更新只补新内容，`archive.html` 持续合并——像本地镜像一样越用越全
- **低风控设计**：请求从你已登录的 misskey.io 页面上下文发出（与正常浏览同源同会话），拟人节奏 + 自动退避，提供三档安全预设
- **离线 HTML 档案**：仿 Misskey 风格时间线 + 右侧媒体抽屉 + 灯箱查看器，深浅色主题
- **过往记录与增量去重**：自动记录下载过的内容，再次抓取默认只处理新内容
- **多种导出**：增量档案 / 快照 ZIP / 单文件 HTML / 纯图片 ZIP / 元数据 JSON+CSV
- **🏠 项目启动页**：安装后自动打开（界面语言跟随浏览器，可切换中文/日文/英文）——三步上手引导、抓取状态实时显示、初始偏好设置、版本与更新日志

## 📦 安装

**方式 A（推荐）**：从 [Releases](../../releases/latest) 下载最新版 zip，解压得到 `misskey-image-grabber` 文件夹

**方式 B**：下载本仓库源码（Code → Download ZIP，或 `git clone`）

然后：

1. 浏览器打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
2. 右上角开启「开发者模式」
3. 「加载解压缩的扩展」选择 `misskey-image-grabber` 文件夹（含 `manifest.json` 的那一层）——首次安装会自动打开**项目启动页**（选语言、三步上手、初始偏好）；版本更新后打开扩展页会定位到更新日志
4. （可选）修改代码后点扩展卡片上的刷新图标 ↻ 生效

> 扩展目录内不能包含 `_` 开头的文件/文件夹（系统保留名），否则加载失败。

## 🚀 使用

**日常流程（增量模式）**：

```
打开用户主页 → 点右下角「抓取此用户的图片」按钮 → 抓取 → 更新本地档案 → 打开 archive.html
```

1. **入口**：打开某用户的 misskey.io 主页，点右下角绿色按钮（自动填好用户名）；或点工具栏扩展图标手动输入 `@用户名` / 主页链接
2. **抓取**：配置参数后开始，可暂停/停止；任务自动保存，中断后可继续
3. **导出**：勾选图片（默认跳过已拥有的），选择导出方式
4. **查看**：ZIP 解压（或直接写入的文件夹）中双击 `archive.html`

## ⚙️ 设置项说明

### 🛡 安全风险预设

| 预设 | 请求间隔 | 分页 | 停顿策略 |
|------|---------|------|---------|
| **稳健（最安全）** | 2.5–6.5 秒随机 | 10 条/页（与官方网页端一致） | 每 8–15 页长停顿 45–120 秒；每 20–30 页批次休息 8–20 分钟；图片下载最温和 |
| **平衡（默认）** | 0.9–2.6 秒随机 | 40 条/页 | 适度长停顿与批次休息 |
| **快速（不推荐）** | 0.7–2 秒随机 | 100 条/页 | 每 20–40 页长停顿 10–30 秒；每 40–60 页批次休息 5–10 分钟 |

> 过滤器排除一切内容时（如最小宽度极大），抓取会在「从开始 0 条入账 + 连续 20 页无新增」时提前停止并保留断点，可从横幅继续——避免无意义地扫描全部历史。

> 诚实说明：预设能把行为压到与正常浏览一致，但任何批量抓取都无法"绝对不可见"（服务器天然知道你的账号取了哪些数据）。请配合「最多笔记数」控制总量。本工具不含账号/IP 轮换、指纹伪装等对抗手段；被限流时自动指数退避（20s→60s→180s）暂停任务。

### 🌐 界面语言

首次安装时**自动跟随浏览器语言**（中文系统→中文、日文系统→日文，其余英文）。管理页右上角「Language · 语言 · 言語」可随时切换（中文/日文/英文），与启动页选择联动（同一全局设置）。「📖 档案页与下载」中的**档案页语言**可单独指定生成档案的界面语言（默认跟随界面），方便把档案分享给其他语言的用户。

### 🎯 抓取范围

高效模式（API 端只取带图笔记，不含回复）/ 全覆盖模式（含回复图片）· 抓取节奏 · 每页数量 · 最多笔记数 · 最多图片数 · 日期范围 · 含转贴 · 仅原创

### 🔍 内容过滤

图片格式（JPG/PNG/GIF/WebP/AVIF，部分勾选才过滤）· 最小宽/高（可跳过表情包小图）· 最小文件大小 · 完全跳过敏感内容

### 📁 文件命名与目录

命名模板：`日期时间_笔记ID_序号`（默认）/ `笔记ID_序号` / `日期_序号` / `保留原始文件名`（重名自动去重）· 子目录组织：平铺 / 按年 / 按年-月

### 💾 保存位置

- **浏览器下载文件夹**（默认）：`下载文件夹/MisskeyGrab/`
- **自选文件夹**：系统目录选择框指定位置，导出**直接写入**（不弹下载栏）；授权跨会话记忆，失效自动回退

## 🗂 过往记录（增量与恢复）

- **自动记录**：每次导出成功，自动记录「用户 → 文件 ID」与笔记数据
- **增量跳过**：再抓同一用户时，已拥有的图片标「✓已拥有」并默认跳过；一键「仅新内容」
- **自动备份**：每次导出后自动把全部记录写到 `_data/misskey_history.json`
- **📂 导入记录**：换浏览器/重装后导入备份 JSON 即可恢复（文件并集、笔记按 ID 合并）
- **🔍 扫描档案库**：连记录 JSON 都丢了也能恢复——扫描磁盘上各用户文件夹的 `_data/data.json` + `images/`，核对文件真实存在后反推重建下载记录（命名沿用 Plex「扫描资料库」的惯例）
- **♻ 重新生成 HTML**：样式更新后，老档案无需重新抓取——直接用已存储的笔记 + 磁盘图片按最新样式重建 `archive.html`（命名沿用 WordPress「重新生成缩略图」/构建系统「Rebuild」的惯例）
- **📂 打开下载文件夹 / 打开 HTML**：一键在文件管理器中打开 MisskeyGrab 目录；每位用户的档案可直接在浏览器中打开查看
- **过往记录页**：查看所有抓过的用户，支持单独清除、清空全部、导出备份

## 📖 档案页特性

**时间线**：仿 Misskey 风格 · 每条笔记含时间/正文/图片网格/反应统计 · 正文安全渲染（链接、@提及、#话题、自定义表情、粗体/删除线、引用、CW 折叠）· 关键词搜索 · 深/浅色主题 · `content-visibility` 按需渲染（大档案流畅滚动）

**📅 时间导航**（左侧面板）：月历点击任意日期直达该天 · 「快速/平衡/稳健」三档预设下都能精确跳转 · 底部活跃度轴可拖动按时间快速定位（悬停预览日期）· 左下角胶囊实时显示当前所在月份 · 首次安装界面语言自动跟随浏览器

**🖼 媒体抽屉**（X Media 标签式）：默认收起、正文满宽阅读；边缘「🖼 图片栏」标签或工具栏按钮呼出；约 180px 目标列宽的瀑布流，列数随宽度自适应 2–5 列，「最短列优先」分配保持时序；抽屉内「敏感」开关

**💡 敏感图遮罩**（misskey.io 式）：真实图片 + CSS 高斯模糊 + 轻压暗 + 角标，揭示即去模糊；抽屉内第一次点击就地揭示、第二次进灯箱

**🔎 灯箱**：图片放大至 86% 视口 · 顶部胶囊：计数 + 「查看原图」（新标签页全分辨率，原生缩放看细节）+ 「跳到这条笔记」（定位高亮，自动展开 CW/揭示敏感）· 底部**隐藏式胶片条**（悬停滑出/点击固定，快速跳转）· **滚轮直接切换上/下一张**（胶片条自动跟随居中）· ←/→ 翻页 · Esc 分层关闭（先灯箱后抽屉）· 页面滚动位置全程保留

**🎨 图标**：界面图标全部为手绘线性 SVG，颜色随主题与悬停状态自动变化，跨平台显示一致

## 📤 导出方式

| 方式 | 说明 |
|------|------|
| **📖 更新本地档案**（推荐日常） | 增量合并进 `用户名/archive.html`，只下载新图片，结构文件覆盖写入不产生副本 |
| 📚 HTML 档案快照（ZIP） | 本次抓取内容的独立快照，存入 `_snapshots/` |
| 📁 HTML 档案快照（文件夹） | 同上，不打包直接落文件夹 |
| 📄 单文件 HTML | 图片 base64 内嵌，单文件转移 |
| 🖼 纯图片 ZIP | 仅图片 + 元数据 |
| 🧾 仅元数据 | data.json + metadata.csv |

## 📂 导出目录结构

```
MisskeyGrab/                     ← 或你自选的文件夹
  <用户名>/                       ← 每个用户一个档案夹
    archive.html                 ← 入口：双击即看全部内容
    images/                      ← 档案页引用的图片（含头像/表情，URL 哈希命名防重复）
    _data/                       ← 收纳：data.json / metadata.csv / misskey_history.json 记录备份
    _snapshots/                  ← 收纳：各时间点的快照 ZIP / 单文件 HTML / 快照文件夹
```

## ⚠️ 已知限制

- 仅针对 misskey.io（支持其他实例需改 manifest 权限与 `content.js` 的 ORIGIN）
- 仅抓 `image/*`，不含视频/音频
- 图片为实例提供的公开版本（webpublic），非上传原图
- 正文按 MFM 子集渲染，复杂语法（动画等）不渲染
- 清空「过往记录」会同时清掉增量档案的合并数据（磁盘文件仍在，但下次会重新建档）

## 🧰 项目结构

```
manifest.json       MV3 清单
background.js       service worker：打开/复用管理页
content.js          misskey.io 注入：抓取按钮 + token 采集 + API 同源中继
manager/            管理页（设置 / 进度 / 导出 / 过往记录 / 自选文件夹）
onboarding/         项目启动页（三语欢迎 / 状态自检 / 初始偏好 / 更新日志）
lib/api.js          API 客户端（限流退避、超时换路、token 失效降级）
lib/crawl.js        分页抓取循环（拟人节奏、批次休息、断点续抓）
lib/render.js       archive.html 生成器（MFM 子集、媒体抽屉、灯箱、时间导航、CSV/JSON）
lib/archstore.js    增量档案合并存储
lib/history.js      下载过往记录（导入/导出/合并）
lib/recover.js      扫描档案库核心
lib/store.js        chrome.storage 持久化
lib/zip.js          零依赖 store-only ZIP
lib/util.js         工具函数（过滤、命名、哈希等）
```
